# 0008. REPLAY_MODE로 키 없이 데모와 평가를 재현한다

상태: 채택

## 맥락
ShipFinder와 UNI-PASS 약관상 실제 응답 원본을 레포에 커밋할 수 없다. 채점자와 팀원이 키 없이도 돌려 볼 수 있어야 한다 (SDD 6.6절 완료 기준: clone 후 10분 안에 `/health` 200과 데모 B/L 1건 응답).

## 결정
- `REPLAY_MODE=true`면 외부 API 대신 `evals/fixtures/`의 가공 응답을 읽는다. 데모 B/L은 13건(라이브 데모 `DEMO..` 10건 + 평가셋 TESTBL01, 04, 26)이다.
- fixture는 실제 응답과 형식만 같은 가공값이다. 실제 수집값은 DB에만 둔다.
- 평가셋 30건은 시계를 2026-09-22 12:00(KST)에 멈추고 재생한다.
- 재생 모드 서버는 데모 위치가 약 5시간 반 뒤 오래된 위치가 되므로 4시간마다 재생 파일을 다시 만든다.
- 용도는 채점자 재현, 키 없는 로컬 데모, 평가다. 배포 서버는 쓰지 않는다 (ADR 0010).

## 대안
근거 문서에 비교한 대안이 적혀 있지 않다.

## 결과
좋아진 것: 테스트와 평가가 키 없이 돈다. 대가: 지연이 실제보다 짧고, 실제 API 오류 모양은 문항으로 만든 것만 본다 (`EVAL_REPORT.md` 3-1절). 6.6절의 다른 노트북 재현 기록은 레포에 없어 미확인이다.
