# 0010. 배포 서버는 재생 모드가 아니라 실제 모드로 돌린다

상태: 채택 (처음 결정을 대체함)

## 맥락
처음엔 배포 서버도 재생 모드(`REPLAY_MODE=true`)였다. Railway용 Dockerfile 작업 때 "배포는 데모로 시연"으로 정했고, 재생 모드면 켜질 때 데모 재생 파일을 만들게 했다 (커밋 186b830, 2026-10-05).

## 결정
배포된 api는 `REPLAY_MODE=false`(실제 모드)로 돈다. 문서에 배포 모드를 쓸 때는 이 한 가지로만 쓴다. 재생 모드는 채점자, 키 없는 로컬 데모, 평가용이다.

## 대안
- 재생 모드 배포 유지: 데모 위치가 약 5시간 반 뒤 오래된 위치가 되어 결과가 바뀌는 문제가 있었다 (커밋 c577c56의 메시지, README 298행). 실제 모드로 바꾼 직접 이유는 근거 문서에 명시되어 있지 않다.

## 결과
좋아진 것: 운영 채팅의 입항 선박 검색이 실제 선박 목록을 돌려줬다(예: 일본에서 1주 안에 부산 오는 수입 화물선 43척, `docs/release_manifest.json` mof_relay.note).
대가: 해수부 API가 Railway 싱가포르에서 막혀 릴레이가 필요해졌다 (ADR 0011). 위 43척은 한 번의 확인이고 지속 가동률은 재지 않았다 (SDD 6.7절).
