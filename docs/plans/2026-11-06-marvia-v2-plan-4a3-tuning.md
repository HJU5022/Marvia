## 지킬 것

- 평가셋 v2와 그 정답 목록은 고치지 않는다. 출력을 본 뒤 `also_ok`를 넓히지 않는다.
- 문항 이름이나 질문 글을 지시에 넣지 않는다. 지시는 문항이 아니라 질문의 종류를 말한다.
- 다시 잴 때는 설정마다 세 번(에이전트·계획자 Haiku), 평균과 최소~최대로 적는다. 비교 기준은 계획 4a-2의 세 번 실행
  (`c2c068d`)이다.
- CI 문은 바꾸지 않는다(문은 저장한 줄을 다시 세는 검사다).

## Task 1: `not_in_evidence`를 법령 쪽 대상으로 좁힘

- `graph/schemas.py`의 칸 설명과 `prompts/write.md`의 칸 줄: 참은 사용자가 물은 조문·항·규정·시행 시점이 근거 묶음에
  없을 때만이다. 화물 번호나 화물 사실이 없는 것은 해당하지 않는다(그때는 묻거나 포워더 메시지로 안내한다).
- 시험(키 없음): 칸 설명과 작성자 지시가 같은 범위를 말하는지(화물 번호·화물 사실 제외 문장이 둘 다에 있음).
  모델 행동은 Task 3에서 잰다.

커밋: `fix(graph): 근거 없음 칸을 법령 쪽 대상으로 좁힘`
