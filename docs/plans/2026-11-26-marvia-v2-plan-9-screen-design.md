# Marvia v2 계획 9: v1의 화면 디자인 위에 v2 기능을 올린다

> 진행 방법: 커밋 하나는 동작 하나다(`feat(web): ...`). 서버와 `web/lib/agui.ts`, `web/lib/auth.ts`의 동작은 건드리지 않는다.

**Goal:** 배포한 v2 화면이 꾸밈 없는 빈 페이지라 못 쓴다. v2 화면은 "v1 디자인 + v2 기능"이어야 했다. 계획 4b와 설계 10절 어디에도 v1의 모양을 버린다는 결정이 없었으니 빠뜨린 것이고, 지금 메운다. v1(`v1-final:web/DESIGN.md`)의 시각 규칙과 틀을 v2의 한 쪽짜리 화면에 그대로 입히고, v2가 새로 갖는 기능(계획 진행, 이렇게 읽었어요, 선택지·승인 카드, 근거 패널, 화물 카드와 배 식별 칸, 409 안내, 계정 삭제)을 그 틀 안에 둔다.

## 기준 (v1 DESIGN.md에서 가져온다)

| 규칙 | 값 |
|---|---|
| 바탕은 흰색, 구분은 가는 선. 그림자, 그라데이션, 유리 효과, 다크 모드, 이모지를 쓰지 않는다 | `--bg`, `--surface` `#ffffff`, `--border` `#e8e8e8` |
| 모서리는 각지게 (원형 점만 예외) | `--radius` 0 |
| 파랑은 누를 수 있는 것에만 | `--brand` `#2962f5`, hover `#1d4fd7` |
| 신호등 색은 판정 등급(순항, 주의, 긴급)에만. 그 밖에는 회색이나 파랑 | `--grade-fine`, `--grade-watch`, `--grade-act` |
| 글자 색은 세 단계 | `--text`, `--text-2`, `--muted` |
| 글꼴은 번들만. 영문과 숫자는 Manrope, 한글은 Noto Sans KR, 고정폭 IBM Plex Mono는 B/L과 컨테이너 번호에만 | 바깥 글꼴 서버 요청 0 |
| 글자 크기는 토큰으로만. 본문 14px | `--text-xs` 12, `--text-sm` 13, `--text-base` 14, `--text-lg` 18, `--text-xl` 22 |
| 제목은 굵게 (h1 700, h2와 h3 600) | |
| 주 버튼은 파랑 채움, 보조 버튼은 회색 외곽선 | `.button.primary`, `.button.secondary` |
| 아이콘은 lucide 선 아이콘만 | `lucide-react` |
| 움직임 토큰 150, 220, 320ms. `prefers-reduced-motion: reduce`이면 모두 끈다 | `--t-fast`, `--t-enter`, `--t-panel` |

## 틀 (v1 chat 화면과 같게)

- 위 줄(로고, 로그아웃, 계정 삭제). v2에는 v1의 사이드바가 가리킬 쪽이 없어 위 줄만 둔다.
- 결과가 없으면 대화만 가운데. 결과(계획, 읽은 값, 화물, 근거)가 생기면 대화(왼쪽)와 상세(오른쪽)를 40:60으로 나눈다. 대화 칸은 `clamp(380px, 40%, 720px)`.
- 대화 칸: 답과 대화, 선택지와 승인 카드, 입력창(맨 아래). 상세 칸: 계획, 이렇게 읽었어요, 화물, 근거.
- 900px 이하: 상세가 아래에서 올라오는 시트가 되고 접으면 손잡이 줄만 보인다. 700px 이하: 위 줄을 좁히고 세로로 쌓는다.
- 입력창: Enter로 보내고, Shift+Enter는 줄바꿈, 한글 조합 중 Enter는 무시, 500자까지.
- 이 화면에서만 페이지 전체가 아니라 안쪽 칸이 스크롤한다.

## 하지 않는 것 (v2 서버에 길이 없다, 서버 일이 필요하다)

대화 목록과 기록, 서류와 사진 올리기, 사용량, 배 상세, 감시 목록과 지도, 카카오, 관리자, 지표, 소개 랜딩. 이식하지도 비워 두는 틀을 만들지도 않는다. 지도 라이브러리(maplibre, leaflet)도 넣지 않는다. v2 서버의 길은 `POST /agui`, `DELETE /account`, `GET /health` 셋이다.

## 지킬 것

- `web/lib/agui.ts`와 `web/lib/auth.ts`의 동작은 그대로 둔다.
- 접근 가능한 역할과 이름을 바꾸지 않는다(화면 시험의 선택자가 산다). 바꿔야 하면 시험을 함께 고치고 적는다.
- 새 의존성은 정확한 버전으로 고정한다: `lucide-react` 1.71.0, `@fontsource-variable/manrope` 5.3.0, `@fontsource/ibm-plex-mono` 5.3.0. 글꼴은 번들하고 바깥 요청은 없다. `web/THIRD_PARTY.md`에 출처와 라이선스를 적는다.

## 끝났다고 말하는 기준

1. `npm run typecheck`와 `next build`가 오류 없이 끝난다.
2. 공식 Playwright 1.64.1 이미지에서 기본 흐름 네 개와 `E2E_VESSEL=on` 흐름이 통과한다(workers 1, retries 0). axe serious와 critical 0건. 브라우저에서 Anthropic과 Voyage로 가는 요청 0건.
3. 화면 그림(`web/e2e/screenshots`)을 다시 만든다. 가로 데스크톱과 폭 390px에서 로그인, 빈 대화, 근거와 화물이 있는 답, 선택지 카드, 승인 카드. DEMO 번호만 보인다.
4. v1 규칙을 어기는 값이 없다: 그림자, 그라데이션, 둥근 모서리, 바깥 글꼴 요청, 이모지.
