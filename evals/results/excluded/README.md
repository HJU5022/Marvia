# 평가 지표 화면과 집계에서 뺀 결과 파일

평가 지표 화면(`backend/app/services/account/metrics.py`)은 `evals/results/` 바로 아래의 `*.json`만 읽는다. 이 폴더의 파일은 원본으로 남기되 화면과 최신 결과 집계에는 쓰지 않는다.

| 파일 | 뺀 이유 |
|---|---|
| `b_20261009_1831.json` | 라우팅 켬 2회차. p95가 909,292ms로 깨졌다. N02는 LLM 호출이 5초인데 문항 전체가 2,080초였고, N04도 연결 실패 뒤 15분이 비었다. LLM 호출 밖에서 문항이 멈춘 값이라 지연 비교에 쓸 수 없다. 같은 측정 환경의 다른 회차도 연결 실패가 6건 있었다. 같은 코드를 네트워크가 안정된 상태에서 다시 잰 `b_20261011_1452`·`b_20261011_1454`는 LLM 호출 p50 1.7~1.8초, 문항 p95 5.5초(1회차 16.2초는 제공사 무응답 60초 상한 1건)로 이전 측정과 같은 수준이었다. 요청당 비용과 라우팅 비율은 이 파일에서도 정상으로 남아 있어 `docs/specs/model-routing.md`의 비용 평균에는 이 경로로 그대로 쓴다 |
