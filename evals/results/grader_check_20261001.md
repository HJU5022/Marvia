채점 모델(google/gemini-2.5-flash)이 서비스 모델(openai/gpt-4o-mini)의 통관 해설을 맞게 채점했는지 사람이 본다.
원본: evals/results/b_20261001_1953.json (23건 채점, 12건 1점, 0.522). 아래 5건은 1점 1건, 0점 4건이고 0점 사유가 서로 다른 것으로 골랐다.

## 사람이 하는 일

각 행의 "사람 점수"에 0 또는 1, "채점 맞나"에 O/X를 적는다. 기준은 채점 모델과 같은 아래 다섯 조건과 skills/customs-stages/SKILL.md 표다.
LLM으로 채우지 않는다 (CLAUDE.md 평가셋 규칙과 같은 이유: 채점 기준을 확인하는 자료다).

1. 단계의 뜻이 표와 맞다
2. 다음 단계가 표와 맞다. 표에 없는 단계면 뜻을 추측하지 않고 관세사 확인을 안내한다
3. 관세나 통관 가부를 판단하지 않는다
4. 단계나 표에 없는 사실을 말하지 않는다
5. 수입자가 알아들을 쉬운 말이다

참고 (SKILL.md 표)
- 입항적재화물목록 심사완료: 뜻 "세관이 목록을 확인했다", 다음 단계 "하선신고 수리", 사용자가 할 일 "없음"
- 관세사 확인 조건: 단계 이름에 검사·보류·정지·반송·폐기가 들어가면 바로 관세사에게 연락, 표에 없는 단계는 뜻을 추측하지 않고 관세사 확인 안내

## 보면서 걸리는 점 (판단은 사람이)

- B10: 단계 이름에 "검사"가 들어가 관세사 확인(true)은 SKILL 조건에 맞아 보인다. "세관의 검사가 필요합니다"가 뜻 추측인지가 쟁점이다
- F06: 0점 사유가 쉬운 말(5번)뿐인데 needs_broker true(할 일 없음 단계)는 이유에 없다. 사유가 맞는지 볼 것
- N08: 이유 두 개 중 5번(쉬운 말)이 맞는지 볼 것
