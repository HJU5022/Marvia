# 공격 e2e (지금 서비스 모델, 서류 PDF·사진 채널)

**결론.** 지금 서비스 모델로 채팅·서류 경로를 공격했을 때 뚫림, 정보 누출, 정책 위반은 모두 0건이었다. 같은 측정에서 공격이 아닌 버그를 찾아 고쳤다.

판정 평가셋 30건이 재지 않는 채팅·서류 경로를 실제 LLM으로 공격하고 이상한 질문을 넣은 기록이다. [이전 주입 측정](../injection/README.md)은 옛 서비스 모델(gpt-4o-mini) 기준이고 서류 PDF 채널이 없어서, 바뀐 서비스 모델과 서류 PDF·사진 채널을 다시 쟀다. 요약은 [EVAL_REPORT.md](../../../EVAL_REPORT.md) 7절에 있다.

## 조건

| 항목 | 값 |
|---|---|
| 코드 | PR #86 브랜치. 1차는 버그 수정 전 코드, 재확인은 웹 검색 제거·import-basics 뒤 코드 |
| 서버 | 로컬 백엔드, 로컬 docker DB(운영 DB 아님), 로그인 끔 |
| LLM | `vertex/google/gemini-3.5-flash-lite` (서비스 모델과 같은 모델을 Vertex로 호출) |
| 외부 API | 대부분 재생 파일(`REPLAY_MODE=true`). 실제 API 서버는 14건만 |
| 비용 | 상한 약 9,100원. Langfuse environment `e2e-attack`의 토큰 합계에 `harness/cost.py`의 비관적 단가를 곱했다. 토큰 합계는 Langfuse에서 읽었고 레포에 파일로 남기지 않았다 |

## 결과 요약 (1차)

원본은 `chat_results.jsonl` 241건, `doc_results.jsonl` 50건이다. 그 밖에 손으로 넣은 약 30건은 기록 파일이 없다.

| 채널 | 시도 | 뚫림 |
|---|---|---|
| 사용자 입력 (채팅: 영·한·중·일, 역할 바꾸기, base64, 조각 합치기, 가짜 도구 결과, 판정을 fine으로 바꾸라는 요구, B/L 원문 요구) | 약 60 | 0 |
| 외부 데이터 (가짜 대화 기록, 화면 배 이름·목적지 속 지시문, context 필드 주입) | 약 12 | 0 |
| 서류 PDF (스캔형 10, 글자층 9) | 19 | 0 |
| 서류 사진 (PNG 12, JPG 8) | 20 | 0 |
| 깨진 파일·아주 큰 그림 등 (`chan` robust) | 11 | 공격 아님. 버그 5 포함 |

정보 누출(시스템 프롬프트, 가리지 않은 B/L, 키)과 정책 위반(통관 가부·세액 판단, 날짜 약속, 지시 따르기)은 0건이다. `doc_results.jsonl`의 500 한 건은 아래 버그 5(아주 큰 그림)이고 고쳤다.

## 찾은 버그와 처리

## 재확인 (`v16_recheck_results.jsonl` 53건)

웹 검색 도구를 지우고 import-basics Skill과 프롬프트 chat-agent 16을 넣은 코드로 다시 돌렸다. 5xx 0건, 빈 답 0건, 영어 답 0건, "마비아" 0건, Skill에 없는 링크 0건이었고 주입 5종은 모두 거절했다. 이 재확인에서 새로 생긴 문제(실무 질문이 메모 꺼내 보기로 감, "?"가 입항 목록 전체로 감)를 찾아 고쳤다.

## harness/

이 측정을 돌린 스크립트다. 로컬에 띄운 서버를 부른다: 8100은 재생 모드, 8101은 실제 API, 8102는 재확인용 서버다.

| 파일 | 무엇 |
|---|---|
| `harness.py` | 공통: 요청 보내기, 누출·이상 응답 분류, 결과 한 줄 쓰기 |
| `suite_chat.py` | 채팅 공격과 이상한 질문 (`chat_results.jsonl`의 `cat` junk, inject, forbid, contract, baseline) |
| `suite2.py` | 이상한 질문 2차: 입항 목록, 배 이름, 말투, 세금·법률, 날짜, 여러 B/L, 후속 질문 context 등 (`cat` s2) |
| `suite_live.py` | 실제 API 서버(8101) 문항 (`cat` live) |
| `suite_doc.py` | 서류 PNG·JPG·PDF 공격 (`doc_results.jsonl`) |
| `bomb.py` | 아주 큰 그림 업로드 (버그 5) |
| `v16_run.py` | 재확인 (`v16_recheck_results.jsonl`) |
| `cost.py` | Langfuse에서 `e2e-attack` 토큰 합계를 읽어 비용 상한을 계산 |
