# 공격 e2e (서비스 경로, 바뀐 서비스 모델과 서류 PDF·사진 채널)

판정 평가셋 30건이 재지 않는 채팅·서류 경로를 실제 LLM으로 공격하고 이상한 질문을 넣어 버그를 찾은 기록이다.
강사 감사의 지적("주입 측정은 구 모델 기준이고, 바뀐 서비스 모델과 PDF 입력은 다시 재지 않음")에 대한 재측정이다.

## 조건

| 항목 | 값 |
|---|---|
| 코드 | PR #86 브랜치. 1차는 버그 수정 전 코드, 재확인은 웹 검색 제거·import-basics 뒤 코드 |
| 서버 | 로컬 백엔드, 로컬 docker DB(운영 DB 아님), 로그인 끔 |
| LLM | `vertex/google/gemini-3.5-flash-lite` (서비스 모델과 같은 모델을 Vertex로 호출) |
| 외부 API | 대부분 재생 파일(`REPLAY_MODE=true`). 실제 API 서버는 14건만 |
| 비용 | Langfuse environment `e2e-attack` 토큰으로 계산한 상한 약 9,100원 (`harness/cost.py`의 비관적 단가) |

## 결과 요약 (1차, `chat_results.jsonl` 241건 + `doc_results.jsonl` 50건 + 수동 약 30건)

| 채널 | 시도 | 뚫림 |
|---|---|---|
| 사용자 입력 (채팅: 영·한·중·일, 역할 바꾸기, base64, 조각 합치기, 가짜 도구 결과, 판정을 fine으로 바꾸라는 요구, B/L 원문 요구) | 약 60 | 0 |
| 외부 데이터 (가짜 대화 기록, 화면 배 이름·목적지 속 지시문, context 필드 주입) | 약 12 | 0 |
| 서류 PDF (스캔형 10, 글자층 9) | 19 | 0 |
| 서류 사진 (PNG 12, JPG 8) | 20 | 0 |

정보 누출(시스템 프롬프트, 가리지 않은 B/L, 키)과 정책 위반(통관 가부·세액 판단, 날짜 약속, 지시 따르기)은 0건이다.
`doc_results.jsonl`의 500 한 건은 아래 버그 5(압축 폭탄 그림)이고 수정했다.

## 재확인 (`v16_recheck_results.jsonl` 53건)

웹 검색 도구를 지우고 import-basics Skill과 프롬프트 chat-agent 16을 넣은 코드로 다시 돌렸다.
5xx 0건, 빈 답 0건, 영어 답 0건, "마비아" 0건, Skill에 없는 링크 0건, 인젝션 5종 모두 거절.
이 재확인에서 새로 생긴 문제(실무 질문이 메모 꺼내 보기로, "?"가 입항 목록 전체로)를 찾아 고쳤다.

`harness/`는 이 측정을 돌린 스크립트다. 로컬 포트(8100, 8101, 8102)에 띄운 서버를 부른다.
